# Pravah CDN — API Testing Collection

This directory contains the API test collection for the Pravah Distributed CDN. It is structured using the OpenCollection / Bruno format and can be imported directly into Bruno, Postman, Insomnia, or executed via CLI test runners.

---

## Directory Overview

```
pravah-api-tests/
├── admin-api.yml              # Admin-level management and DLQ replay endpoints
├── opencollection.yml         # OpenCollection specification metadata
│
├── auth/                      # Authentication & Token Management
│   ├── register.yml           # User registration
│   ├── login.yml              # Password verification & JWT issuance
│   └── generate-new-access-and-refresh-token.yml # Token rotation
│
├── upload/                    # Resumable Chunked Ingestion
│   ├── upload-init.yml        # Session initiation with checksum & chunk count
│   ├── upload-chunks.yml      # Multipart binary chunk upload
│   ├── upload-complete-post.yml # Full assembly, checksum verification & Kafka dispatch
│   └── upload-versions.yml    # Versioned object updates (v2, v3)
│
├── download/                  # Content Delivery & Streaming
│   ├── direct-minio-download.yml # Origin fallback verification
│   ├── partial-download-file.yml # HTTP 206 Byte-Range streaming
│   ├── signed-url-media.yml   # Time-limited cryptographic signed URLs
│   └── specific-version-download.yml # Versioned file retrieval
│
├── health-check/              # Regional Liveness & Node Telemetry
│   ├── health-check.yml       # Sub-millisecond health ping
│   └── get-healthy-nodes.yml  # Active routing candidates list
│
├── metadata/                  # File Records & Version History
│   ├── get-files.yml          # List active file catalogue
│   ├── get-file-by-id.yml     # Retrieve single object metadata
│   ├── version-history-of-file.yml # Audit version progression
│   └── delete-file.yml        # Cascade delete & Kafka invalidation broadcast
│
├── user/                      # User Profile & Sessions

│
└── test-files/                # Sample Payloads

    ├── test-cache.txt         # Cache hit verification payload
    └── test.mp4               # Video transcoding sample
```

## Environment Variables Configuration

Configure the following variables in your API client:

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `baseUrl` | `http://localhost:3000` | Pravah Central Core Control Plane API |
| `edgeUrl` | `http://localhost:3001` | Pravah Regional Edge Data Plane Ingress |
| `token` | `<jwt-token>` | Bearer token generated by `POST /api/v1/auth/login` |
| `fileId` | `<uuid>` | Unique identifier of an uploaded test file |

---

## Execution Workflow

1. **Authenticate:** Run `auth/login.yml` to acquire a valid JWT access token.
2. **Initialize Upload:** Execute `upload/upload-init.yml` to register file metadata and acquire an upload session.
3. **Upload Chunks:** Stream binary payload chunks using `upload/upload-chunks.yml`.
4. **Finalize Assembly:** Complete the file with `upload/upload-complete-post.yml`.
5. **Verify Edge Delivery:** Request the file through `download/direct-minio-download.yml` or via the Edge URL (`GET /edge/content/:fileId?v=1`) to confirm cache population.
